# ADR-0001：方案 B：会话级定时唤醒归档检测（archive-lib/timer 引擎 + daemon-loop 插件）

> 状态：accepted

## 背景

- 原 SKILL §10 为**惰性检测点版**（会话加载/收尾/手动三触发点），零自动性；「谁定时唤醒」缺执行者是真实事故根因（会话静默后无人触发归档检测）。
- 用户拍板方案 B 语义：**每会话独立 idle 计时器 → 到点自动唤醒进归档检测 → 唤醒后计时器清理 → 历史会话重启/继续重新计时**。
- 环境：cordis-plugin-timer 宿主定时服务现成；DSH 插件注入管线可用（dev_scaffold/build/inject）；历史越界半成品已按回滚处置（14/3 → 13/13 基线）。

## 决策

1. **引擎层（单一事实源，scripts/）**：
   - 新增 `archive-lib.mjs` 公共层：转录定位/解码/mark 读写/信号召回/pending 队列；**env 隔离**（`ARCHIVE_LOG/ARCHIVE_PENDING/ARCHIVE_SESSIONS/ARCHIVE_SILENT_MS`）供插件与测试容器使用。
   - 新增 `archive-timer.mjs`：`--due`（**发现步**：静默超阈值且无 mark 的会话自动建 mark——补「agent 忘 touch/工具型会话无协议」的脱管缺口，`ARCHIVE_DISCOVER=0` 可关、`ARCHIVE_DISCOVER_BATCH` 每 tick 限批最旧优先；→ fireAt 到点 → 资格门控行数≥50 → 机械信号召回 → 落 `audit/archive-pending/<sid>.json` → 置 pending/清 fireAt=**唤醒后清理**）、`--watch` 周期常驻、`--status`、`--pending-list`（均支持 `--json`）。
   - 改造 `archive-mark.mjs`：行结构扩展 `{pending, lastTurnAt, fireAt}`；新增 `--touch`（活跃重计时/清 pending）、`--pending`。
   - 改造 `archive-check.mjs`：复用公共层；新增 `--json` 结构化输出；T13 输出契约（`增量范围: (N, M]`）保持不变。
2. **协议层（SKILL §9/§10）**：每轮 turn 后 `--touch`；`--due`/`--pending-list` 处理；队列裁决 fork archive-review 子代理（四裁决 ADD/NOOP/MERGE/SUPERSEDE）；存储约束不变（进度在 audit\ 非记忆、候选只落 pending\）。
3. **插件层（薄契约）**：`@dsh-external/dsh-managing-memory` hybrid 形态——daemon-loop 单 tick 调 `archive-timer --due`（宿主常驻解决执行者问题）+ 5 原生工具走引擎 `--json`；**插件不做 LLM 四裁决**。

## 后果

- 正面：自动性补齐（宿主常驻免手动）；重启重计时兜底（fireAt=null 后活跃/新行数据驱动重武装）；done+新行数据驱动失效；CLI/hook/插件三方共用同一引擎；**发现步兜底脱管会话**（忘 touch 的会话静默后仍被纳入，历史会话零协议成本入网）；**活跃保护**（fireAt 到点但转录 mtime 仍新鲜 → rearm 重计时——mtime 是机器可测的活跃证据，忘 touch 的活跃会话不误触发，touch 降级为可选优化）；**数据驱动重武装**（fireAt=null + 已静默 + 转录 size 变化 → 重新武装，mark 记录 lastSize）。
- 成本/副作用：每 turn 一次 touch（协议增量，漏 touch 由发现步+活跃保护双兜底）；mark 行结构变化（旧日志缺新字段按缺省读取，兼容）；watch 常驻模式 CLI 侧需手动终止；发现步「建 mark 与主循环扫描」存在同毫秒竞态点（已修：now 在发现步后采样）；保护/重武装窗口与静默阈值同源（ARCHIVE_SILENT_MS）——极小测试窗口下保护失效属预期，测试需用真实窗口（60s）。

## 替代方案

- A. 维持惰性检测点：零成本但无自动性，事故根因不除——弃。
- B. 每会话独立运行时 Timer：O(N) 膨胀且运行时无常驻执行者——弃。
- C. 计时逻辑全放插件内：破坏「引擎=单一事实源」，CLI/hook 失去同一语义——弃。
- 选定：B 的**语义** + 单 tick 扫描 `--due` 的 O(1) 实现（每 tick 一次全量 mark 扫描，非每会话 Timer）。
