# ADR-0002：方案 C：归档裁决全自动闭环——插件 LLM 调度 + memory-append 安全阀自动入册（无人工环）

> 状态：accepted（v2，2026-09-04 用户拍板全自动闭环）

## 背景

- 方案 B 引擎已自治到「入队」（发现→唤醒→门控→机械消化→pending 队列），但**裁决与固化仍靠人工点火**：每次积压需手动 workflow fan-out（2026-09-03 首轮 302 会话 4 波 33 agents），队列边清边长。
- 复盘三问：① 无自动闭环调度 ② 碎片需治理（已机械消化解决）③ 阶段重复（已 --drain 解决）。本 ADR 解决 ①。
- v1 草案（2026-09-03，proposed）曾保留「权威入册 = 人工一键终审」；用户复核后拍板改全自动（v2）——memory-append 安全阀提供机器层兜底后，人工环取消。

## 决策

1. **执行者 = 插件 daemon-loop**（`@dsh-external/dsh-managing-memory`，inject 增 `llm`）：宿主进程内单轮 LLM 四问裁决，非子代理循环——插件天然是 LLM 宿主（ctx.llm 已有），无需外部调度通道。
2. **裁决触发（节流幂等）**：每次 tick 的 `--due` 后检查——pending 队列 ≥ `adjudicateThreshold`（缺省 5）且距上次裁决 ≥ `cooldownMs`（缺省 5min）→ 逐项裁决（`adjudicateBatch` 条/轮，缺省 10）。
3. **四问裁决单轮 prompt**（输入=队列 signals + 会话元数据）：输出 JSON `{verdict: ADD|SKIP, reason, candidates[]}`：
   - **SKIP**（含重复/注入缓存/一次性/宁缺毋滥）→ 引擎 `mark --done` + `dequeue`（`removePending` 用 rename 隔离替代 rm——safe-delete shim 按 turn 限额拦批量删除，rename 可逆且不触发 shim）。
   - **ADD** → 写 `pending/<当日日期>-arb-<sid前8>.md` 候选（同人工裁决格式：主题/要点/四问/拟落点/溯源）。
4. **自动预合并+固化（v2 核心）**：ADD 候选文件数 ≥ `mergeThreshold`（缺省 6）→ 一次 LLM prompt 读候选提取可复用知识 → 输出结构化落点指令 → 调新引擎 `memory-append` **直接入册**（目标白名单 notes/tools·flows·lessons·env·release.md 既有小节 + MEMORY.md 新索引行须带 → notes 指针）；成功后候选归档 `pending/.processed/`。
5. **安全阀 = memory-append（v2 的机器兜底，替代 v1 人工终审）**：白名单目标 / 无锚小节拒写（exit 2）/ 主文档容量门禁（exit 1）/ 写前备份 `audit\backup-*`——LLM 误判最多被拒写或可回滚，不会污染权威记忆结构。
6. **观察性**：裁决/固化每动作写插件自日志（`~\.dsh\super-injector\dsh-managing-memory.log`）；`--status` 健康度段报「待裁 pending / 距上次裁决 / 累计 ADD」。

## 后果

- 正面：**全自动入册，无人工环**——队列常清、候选自动累积固化，历史积压不再累积（阈值/冷却自动消化）；机械+规则+LLM+安全阀四层各司其职。
- 副作用/风险：LLM 误判 ADD 直接入册——以「宁缺毋滥」prompt 偏置 + 阈值/冷却可调 + memory-append 安全阀硬兜底（越界目标/无锚拒写，写前备份可回滚）；每轮少量 LLM token 成本；裁决质量依赖 ctx.llm 路由可用性（不可用→跳过本轮并记日志，不阻塞）。
- 边界：**不删除既有 pending 候选**（固化后归档 .processed，可逆）；安全阀白名单外目标（USER/AGENT 主文档等）拒写。

## 替代方案

- A. 插件 tick 攒提示、由下个 agent 会话手动 workflow 裁决：仍是人工点火（半自动）——弃。
- B. 引擎内嵌确定性规则裁决（signals 关键词打分）：四问是语义判断，规则无法可靠判 ADD/MERGE——弃（机械消化=唯一的规则层，其余归 LLM）。
- C. 裁决自动但入册留人工终审（v1 方案）：权威库零污染风险最小，但人工环成新瓶颈，用户拍板取消（2026-09-04）——被 v2 取代。
- 选定：A 的引擎自治基础 + B 的边界（规则只做机械消化）+ 插件 LLM 裁决 + memory-append 安全阀自动入册。
