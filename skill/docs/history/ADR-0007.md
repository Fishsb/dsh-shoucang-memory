# ADR-0007：蒸馏固化执行权移交守藏（suite 单一蒸馏器）

> 状态：accepted（2026-09-06 单飞切换已落地）

## 背景

套件产品原则（shoucang ADR-0002）：守藏 = 必装中枢，守藏 + 任意一个成员插件 = 功能完整自循环。
记忆插件的蒸馏固化是**泛用元记忆能力**，记忆插件不装时（守藏 + pmg 组合）知识积累断链——违反自循环原则。
因此蒸馏执行权必须上收到守藏：守藏持唯一蒸馏器，按路由判定分发到各成员库（记忆库 / pmg 卡库 / 守藏本地知识区），白名单不过不存。

记忆插件角色随之重定义（SKILL.md 协作宪章 v2）：**知识库承载 + 引擎供应商**（机械引擎脚本零拷贝复用，MEMORY_ROOT 外化指向守藏本地知识区，ADR-0006）。

## DSH 原生能力对照（架构拍板审查门，2026-09-05 补强）

| 需求 | DSH 原生能力（源码/类型佐证） | 本决策是复用原生还是自建？为何 |
|---|---|---|
| 会话生命周期观测（蒸馏触发） | session/event turn/end + ctx.on | 复用原生（事件驱动 watcher，方案 E 已验证） |
| 子代理执行蒸馏裁决 | subagents.spawn（maxDepth=1，toolFilter 空） | 复用原生（迁移自记忆插件，不改机制） |
| 插件间数据共享 | 文件系统（MEMORY_ROOT 外化 / suite/knowledge 约定） | 复用文件约定；DSH 无跨插件内存共享原语 |

## 决策

1. **唯一蒸馏器**：蒸馏固化事件驱动管线整体迁入 `shoucang-scheduler`（守藏 ADR-0002 阶段 2 已完成 E2E 6/6）。记忆插件 `enableDistill` 缺省改 `false`（watcher 不再注册）。
2. **单飞切换**（本 ADR 落地动作，2026-09-06）：
   - 关记忆插件蒸馏（lib 重编 + 热重载，日志确认「蒸馏 off」）；
   - 开守藏蒸馏（`enableDistill` 缺省 `true` + 热重载）；
   - 水位（16 行）与 pending 积压（26 文件）迁至 `C:\Users\lk\.dsh\suite\knowledge\`，原文件重命名 `.migrated-20260906` 保留（隐藏不删除，可回滚）；
   - 无双写窗口：旧蒸馏器关 + 新蒸馏器开在同一次热重载生效。
3. **记忆插件保留**：记忆库三索引/七类笔记/归档引擎/health-check 等库能力不变；机械引擎脚本供守藏零拷贝调用（MEMORY_ROOT 决定读写根）。
4. **衔接保障**：水位按 sessionId 匹配，迁移保持连续（切换时活跃会话 lastSeq 不丢）；守藏 writeDispatch 对本地知识区走 memory-append 零拷贝写入，记忆库语义不漂移。

## 后果

正面：守藏 + 任意成员插件自循环达成；蒸馏配置（idleWakeMs / llmProvider / llmModel）归守藏；套件单一蒸馏器，无双写去重负担。

副作用 / 成本：记忆插件本体的蒸馏代码保留但缺省不启用（成为冗余代码路径，未来版本可评估移除）；守藏成为蒸馏链路单点（其故障即蒸馏中断，由守藏 ADR-0002 降级链兜底）。

## 替代方案

- **双蒸馏器 + 去重**：记忆插件与守藏并行蒸馏、按哈希去重——被否：双写窗口、去重逻辑复杂、违背"单一蒸馏器"产品原则。
- **记忆插件保留蒸馏、守藏仅转发**：被否——守藏不装时（守藏+pmg）依旧断链，未解决根本问题。
