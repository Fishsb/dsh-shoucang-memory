守藏面板 · UI 三套方案

三页都是可点击的完整原型（左侧导航、页内 Tab / 折叠 / 锚点均可操作）。基础 CSS 与图标取自 client.js 同一份定义；Tab、KPI、锚点条、页脚健康条为方案新增样式，目前只存在于原型页。项目代码未做任何修改。

方案 A · 总览优先激进重构

新增「运行总览」作首屏，8 视图按语义分组，参数页与记忆库由平铺改 Tab。

方案 B · 记忆优先温和重构

首屏改成「记忆库」，8 视图合并为 6 视图（观测与插件集合并入总览），长页保留折叠只加快捷锚点。

方案 C · 保守增强最小改动

视图集合与首屏保持不变，只补 8 个独立图标、页脚健康条、长页锚点条。
