## 1. 跨项目设计规律（14+ 收敛 → 10 条）

1. **常驻/按需两分 + 文件树导航**：记忆文件即目录（Letta MemFS、Cursor/Claude）
2. **条目 = 证据链卡**：引语+proof count（Hindsight）、源事件+判据（dsh-auto-memory）——可溯源可打分可删
3. **审核态 pending→approved**：自动写入前给确认入口（Cursor、Mem0、dsh-auto-memory）
4. **后台进程状态可见**：语义色 pill/徽章（Cognee、Letta sleep、dsh-auto-memory 水位卡）
5. **图谱只做局部邻域**：Obsidian Local Graph、思源聚焦、Zep 子图——单条邻域扩散
6. **渐进披露 + 反链聚合**：聚焦/折叠/面包屑 + 提及面板（思源/Logseq）——条目互为入口
7. **成长 = 增量 diff + 可落盘文件**：Hindsight knowledge pages、Basic Memory
8. **视图与配置分离 + 视图可开关**：Cognee、Obsidian——防密度失控
9. **引用 = 内联注 → 点开高亮原文/时刻**（Mem/Khoj/NotebookLM 收敛）：答→证闭环，不黑箱
10. **自动整理 = 被动浮现 or 定时产出**（Mem Heads Up / Reflect backlinks / Khoj automations）：低打扰双模式

## 2. 设计原则（shoucang 落地版）

- **P1 增量优先**：在 6 视图与 70 类组件上叠加，不推翻（呼应"不破坏"约束）
- **P2 状态可见 > 统计抽象**：蒸馏/深睡/向量都有 pill/徽章态，不黑箱
- **P3 记忆可溯源**：每条（蒸馏产物/深睡[原则]/[路径]/候选）可展开证据链
- **P4 成长有可见物**：delta/周 diff/落盘页——"人格在长"看得见
- **P5 交互闭环**：读（浏览/展开）→ 审（证据链/审核）→ 写（编辑/批准/删除）
- **P6 引用即证**：记忆问答/详情内联数字注，点击高亮来源段（NotebookLM 范式）
- **P7 低打扰浮现**：相关记忆被动浮现（Heads Up 式）优于常驻抢屏；AI 默认静默按需唤醒（Reflect）

## 3. 分视图详设

### 3.1 顶栏状态徽章组（新增，全视图常驻）
- **蒸馏 pill**：idle（灰）/distilling（蓝闪）/done N 条（绿）——Cognee/dsh-auto-memory 水位卡式
- **向量 pill**：fusion（绿）/lexical（灰）/off（暗）——P2 状态可见
- **pending pill**：计数（>0 琥珀）——点击跳记忆板块 §4
- **深睡 pill**：同深度睡眠视图五态（小号徽章复用）
- 实现：panel 侧栏入口下方新增 `sc-nav-group` + 状态行；全部只读轮询 `/memory/overview` + `/vector/status2`（新增）

### 3.2 记忆板块（保留 §1-§6 + 追加）
| 追加 | 内容 | 参考 |
|---|---|---|
| §7 向量召回状态 | provider/模型/缓存行数/最近 mode+耗时/命中示例 | Cognee pill + dsh-auto-memory |
| §8 晨起摘要 delta | 当前内容+剩余有效期+注入次数 | Hindsight pages |
| §9 本周成长 diff | 新增/更新/删除 [原则]/[路径]/notes 清单 | Basic Memory 增量 |
| §4 增强 | pending 行加「批准入册 / 忽略」动作（写门经 write_gate） | Cursor/Mem0 审核 |
| §5 增强 | notes 小节详情页 +「引用/被引用」聚合（反链） | Logseq/思源 |

### 3.3 画像板块（保留结构）
- 指针行**悬停浮现操作**（编辑/详情）——点击弹条目编辑（现有 /memory/sections 只读 → 新增写端点走 write_gate）
- 板块顶追加「最近画像变更」1-3 行（diff 自 delta.md 或审计）
- 不破坏容量卡/进度条/列表结构

### 3.4 参数调节（追加「向量与模型」节）
- 向量开关 / provider 下拉（本地 bge-m3 GPU / 云端）/ 蒸馏模型选择（llmProvider 枚举）
- 蒸馏节流组展示 running vs persisted 差异

### 3.5 深度睡眠视图
- 每次归纳后追加「本次产出证据链卡」：归纳了哪几条 [原则]/[路径]，点开看源（audit 溯源）

## 7. 明确不做（边界）

- 不推翻 6 视图框架与 sc-* 样式语言
- 不做全库大图谱（只做局部邻域反链，P2 渐进）
- 不做常驻 AI 聊天框（P7：被动浮现/按需唤醒）
- 不做模型下载 UI（GPU 服务已固化）
