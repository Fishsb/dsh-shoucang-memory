# 全项目重构判定表：106 模块 ⟷ 文档九概念

> **指令**（用户原话，逐字）：「以这个目标为核心重构整个项目，抛开当前项目的所有约束重构，能用的就用，完全偏离的就改删除重构」
> **性质**：决策态判定表，**不含施工**。每项施工须具名授权。
> **判定口径**（可核）：
> - **留** = 与文档概念**直接对应**且实测在运行（被装配 / 有真机读数）
> - **改** = 对应某概念但**实现偏离**或**半截**（有字段无判据、有代码无出口）
> - **删** = **与文档概念完全偏离**且无运行消费面
> - **让渡** = 该概念**应由 L0 宿主承担**，插件不该实现
>
> **纪律**：引用 [原则] **证据落工作区** —— 每条判定附实测位置；引用 [路径] **多链条改造分册** —— 按依赖序组织，不散点罗列。
