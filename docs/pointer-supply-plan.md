## 1 问题定位（一句话根本决策）

**根本决策：`notes/x.md §y` 是库的地址空间 —— 地址由库侧定义并供给，模型只做选择、不得发明；索引行与其详情小节是「一次写入的两个部分」，必须同事务。**

取证链（四条，逐条可复跑）：

| # | 事实 | 读数 |
|---|---|---|
| ① | 存量悬空指针的来源 | `section-ref-reanchor.mjs` 27 条重指样本，逐条 `git log -S` 回溯首次引入提交：**24 条由 `memory: distill` 引入** · 1 条 snapshot · 2 条无引入提交 |
| ② | 写入面生产集中度 | 库侧触碰主档的 40 次提交中 **39 次 = `memory: distill`**，1 次 = deep-sleep |
| ③ | 机制实锤（行落了、详情从没落） | `87478c4` 新增两行指向 `notes/env.md §ZCode 环境`，**同提交 `notes/env.md` 零改动**；该名在 env.md **全历史不存在**（真名 `ZCode 配置`） |
| ④ | 规模化同型 | `21046e3` 一次蒸馏新增 **55 条**索引行，同提交 `notes/` 只改 **3 项** |

**根因两句话**：
- **地址来源错**：蒸馏 prompt 要求「section = **既有** ## 小节名」，但材料里**从未注入真实小节清单**（`distill-agent.ts:191-198` 只有会话正文 / manifest / 召回行 / pending 候选）⇒ 模型只能凭记忆编名。抽查 5 个典型悬空名，在真库 **334** 个两级小节中 **0 命中**。
- **写入不同步**：`memory-append --new` 原先只校行首标签；且 `writeDispatch` 中 **appends 循环先于 newIndex 循环**，append 因「顶层 ## 需人工建锚」exit 2 失败后 **行照写**（仅 `failed++`）。

## 3 册一 · 地址供给（根因消除）

**目标**：让模型**从清单里选**地址，而不是编地址；判据面从「事后拒收」前移到「事前供给」。

**做法（方向级）**
1. 新增**地址供给段**（材料侧，非 persona）：`notes/<file> → 现有 ## / ### 标题清单`，由库侧现读生成。
2. **单一实现**：清单生成复用 `section-ref` 的 `sectionTitles`（不新写解析器）。
3. **双面接线**（具体落点，改前须逐点核）：
   | 面 | 接线点 | 形态 |
   |---|---|---|
   | 蒸馏 | `distill-agent.ts:191-198` `userInput` 数组 | 新增一段 `## 可用小节地址（appends/newIndex 的 section 必须逐字取自此处）` |
   | 深睡 | `deepsleep-materials.ts` 的 `gatherMaterials` 返回体 | **并入既有「现行树节清单」段**（`deepsleep-materials.ts:58`），不叠第二份 |
   | 生成器 | 新增 `src/section-supply.ts`（薄件：只调 `sectionTitles` + 拼文本 + 预算裁剪） | 供上面两处共用（**单一实现**） |
4. **预算有界**：超出材料预算时降级为「白名单 5 文件 ## 级 + 本段召回命中文件的 ### 级」；继续超则只给 ## 级。⚠ 清单**绝不写进 `distillPrompt`/persona**（用户可自定义且会陈旧），只进材料。
5. **夹具级加固**（非缺口，随册一顺带）：`check-section-ref-parity` 增加合成输入用例，把「spec 吞入 `→ notes/x.md`」的潜在形态钉死（真库 0 例，但**契约不该依赖输入恰好合法**）。

- **阴性对照**：3 节夹具库 ⇒ 清单恰好 3 条、零误报；空库 ⇒ 显式输出「清单 0 条」而非缺段（输入量可见化）。

- **回归红线**：`check-section-refs` 棘轮保持 **0**（只许收紧，不上调基线）。

## 4 册二 · 写入事务化与拒收可见化

**目标**：索引行与它的详情**同生共死**；被拒的知识**可见、可捞**，不再静默消失。

**做法（方向级）**
1. **段级成对裁决**（针对 G2 实测形态）：`appends` 与 `newIndex` 之间建立**段级提交边界**——任一条 append 未成功 ⇒ 该段**不进入** newIndex 落盘（或仅落**与失败 append 无关**的行）。判据用**同 target 文件 + 指针可解析前缀**配对，保守优先。
2. **拒收逐条审计**：`newIndex` 被拒 ⇒ 落 `gate-reject`（含 target / 指针 / 原因分类：missing｜ambiguous｜dup｜容量｜其他），不吞成聚合 `failed` 计数。
3. **未落地知识回退**：被拒的行（含其概况）写入 `pending/` 候选，等下轮重蒸或人工认领 —— **复用既有 project-defer 降级机制，不新造通道**。
4. 水位推进逻辑**不动**（防重演"静默丢料"型历史缺陷）。

**新增判据：内容存在性（补 G2/G7 暴露的空白面）**

> 现有全部机检测的是**地址空间**；本条测**地址背后是否有内容**。这是本册的**核心产出**，不是附加项。
> ⚠ **词面代理已被本轮实测否证**（见下「失败记录」）⇒ 本条**只做确定性判定：正文非空（含非 stub）**，
> **不做语义/词面相似度判定**。

- **形态（v2 · 按实测修正）**：对每条索引行，沿读侧回落语义取**最终落点小节**，判定其「标题后到下一个同级/更高级标题之间」**是否存在非空行**。
  - `0 非空行` ⇒ 记「空壳落点」（**确定性事实，可直接当 FAIL 门**）
  - 正文非空 ⇒ 通过（**不追加词面判定** —— 见失败记录）
- **落点**：新增 `scripts/check-pointer-content.mjs`，登记 `CHECKS`。
  - **真库基线（本轮实测）**：空壳落点 **4 条**，去重 3 小节 ⇒ 可作**棘轮基线 4**（只许收紧）。
  - ⚠ 基线须**先经用户确认**这 3 个空壳的处置口径（回填/重指/废弃）后再下调，否则会锁死待决项。
- **阴性对照**：夹具库放「有内容节 + 空壳节 + 不可解析节」⇒ 只报空壳 1 条，零误报。

**⚠ 失败记录（如实入档，防后来人重走）**：
第一版探针用「行主题词 ∩ 小节正文实词 ≥1」作判据，真库读数 **405/551 = 73.5% 疑似**——
但抽验 `§网络坑`（1812 字）、`§DSH 环境`（16084 字）等**内容充沛的宽节全被判疑似**。
**根因**：索引行用缩写短语（"代理分通道/git不读env"），小节标题是完整名（"网络坑"），
**词面交集天然为零** ⇒ 该代理**在真实数据上失效**，已弃用。
**结论**：内容存在性**只能做确定性的"有没有非空行"**，语义层的"内容对不对"**必须交模型**（本仓既有分工），
不得用词面代理冒充。

**验收方案（成对）**
- **先红夹具**：① 模拟 G2（append 悬空 → 行指向合法小节）⇒ 段级裁决**必须**让行**不落**；② 合法段 ⇒ 行照常落、零 pending（**阴性对照**）。
- **隔离库实跑**：改造前／后双跑读数入档（改造前：行落 + 详情未落 = 已实测）。
- **在册机检**：审计字段存在性（`gate-reject` 带指针字段）+ 回退文件命名规范 + `check-pointer-content` 在册。
- **回归红线**：真库棘轮 0 不变；`check-deploy-sync` 0 不一致。

**不做**：不改容量判据（用户 2026-09-16 判定"提醒即可"）；不删任何既有行；不碰 `_memory/` 以外真源；**不把词面代理当语义判据**（不作 FAIL 门）。

## 5 册三 · 判据单一化收尾 + profiles 准入

**目标**：把 G5/G4 两个"同类判据的第二份实现"收干净——S1R 已完成"读侧/写门/准入"的收敛，**放置与画像两条路还在外面**。

**做法（方向级）**
1. **appends 放置收敛到 `section-ref`**：保留「缺失层自动分裂 `###`」作为**写入策略**，但匹配语义统一为三态（exact 优先 → loose 唯一命中 → 多命中 ⇒ 拒绝并要求「父/子」全路径），删除本地 `findChild`/`matches` 双向包含实现。
2. **profiles § 准入补齐**：`writeProfileLine` 落盘前对行内 `← 源: notes/x.md §y` 跑**同一** `admitIndexRow` 语义（跨面同源，差分锁守）；`missing` ⇒ 拒（与写门同判据），`ambiguous`/`partial` ⇒ 放行 + 提示。
3. 两条都**不新增判据**，只把已有单一实现接上去。

**验收方案（成对）**
- **差分锁扩面**：`check-section-ref-parity` 夹具集纳入**放置决策**（同一 `(文件, 路径)` → 期望落点/拒绝逐例比对）。
- **先红**：现实现下「环境」双向包含命中「DSH 环境」⇒ 夹具应红；收敛后为 ambiguous 或 exact。
- **画像准入先红**：造一条无锚 `← 源:` 行 ⇒ 现落盘、改造后拒。
- **阴性对照**：真库 AGENT/USER 行数不变（97 / 8），棘轮仍 0 —— 证明"只堵新口、不动存量"。

**不做**：不改写存量 0 悬空态（已归零，无存量手术）；不上调任何棘轮基线。
