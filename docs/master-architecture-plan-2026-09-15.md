## 0. 一页结论

**四板块定位（【用户拍板】定稿）**

| 板块 | 语义 | 动作 | 权限 |
|---|---|---|---|
| **库** | **存储** | 载体 | 被写被读 |
| **注入召回** | **消费** | 供给（三层：恒定 / 动态 / 情境） | 只读 |
| **蒸馏** | **产出** | 新增经验（`memAppend(kind:'append'\|'new')`，`src/distill-write.ts:78`） | **只增** |
| **睡眠** | **压缩·提存·提炼·重构** | 库 → 库（`criteria.json:201` 域标签原文即「**巩固域（库 → 库）**」） | **唯一动存量** |

**本轮五条根本结论**

1. **睡眠的本位 = 粒度阶梯的唯一施工者**；但施工场在**库侧**，**不在注入侧**
   —— 注入侧已实测撞墙（可压面仅 302 字符 ≈ 10%，压了会引入指针解析失败模式，P8 **已否决不再重议**，`criteria.json:458`）。
2. **真正的缺口是"跨粒度冗余"**：同一知识以粗（索引行）/细（叙事行）两版**并存且都进注入面**
   （`AGENT.md` L18 ↔ L20、L23 ↔ L47，【读码】+【活体】）。⇒ 睡眠只做了"加粗"，**没做"收细"**。
3. **库的投影层全部可重构，无豁免**（【用户拍板】"没有信息不可以重构"）。唯一红线：
   **未自足期必须可回源；自足后脚手架可弃**（【用户拍板】"源层只是一个记录，可以丢弃"）。
   **认知必须自足**——若一条投影必须靠回源才成立，它是**索引**，不是认知。
4. **睡眠 = 五个动作**：选择 → 压缩 → 收敛 → **释放脚手架** → 降权。
   前四个只是**重排**既有内容，**只有"释放脚手架"让库停止膨胀**（减少依赖面）。
5. **判据分层是横切不变量**（【用户拍板】"各节点积极用向量与大模型介入，增强整个项目运行质量"）：
   缺口**不在"有没有用模型"**（向量已铺开 9 处），而在**"模糊判断被写成了固定规则/常数"**——
   且已实证出错两处（归因方向与数据相反；假冷 26 条）。⇒ 立 **`judgeKind` 三向机检 + 阈值登记制**。

## 3. 目标架构（三张图说清）

### 3.1 粒度阶梯 + 生命周期（单向流，不是固定分层）

```
L3 认知/性格  ┐
L2 原则/路径  ├─ 投影层：**全部可重构，无豁免**（D-7）
L1 精要       │   未自足 ⇒ 必须可回源；已自足 ⇒ 认知独立成立
L0 正文/沿革  ┘
──────────────
脚手架（投入品）← 转录 / audit/*.jsonl / ring-events.jsonl / records.jsonl
                  **可弃 · 不可语义改写**（D-8 + D-12）
```

**自足性三态**：`未自足`（留脚手架，断链即冻结）→ `已自足`（脚手架可弃/冷归档）→ **`再巩固触发`**（消费出反例 ⇒ **退回未自足**，此时丢源 = 永久失去校正机会）。

### 3.2 睡眠的五个动作

| 动作 | 机制 | 现状 | 本轮 |
|---|---|---|---|
| **选择**（哪些进本轮） | 向量（gain） | 🟡 活性/冷度 | 内容水位 + 预算配额（R0） |
| **压缩**（细 → 精要） | 大模型 | ❌ 无通道 | L1 精要层（R2-B） |
| **收敛**（跨粒度去冗） | 向量判同源 | ❌ 只加粗不收细 | 跨粒度收敛（R2-A） |
| **释放脚手架** | 审计复算自足性 | ❌ 无概念 | 自足判定 + 冷归档（R2-C） |
| **降权**（冷/噪声） | 向量 + LLM | 🟡 仅冷度归档 | 见横切册 U2（活性升级） |

### 3.3 判据分层（横切，固定顺序）

```
确定性预筛  →  向量候选  →  大模型判断
（精确/零成本）  （相似/新颖/gain）  （归因/取舍/生成）
```
**这是项目已有模式的原话**（`deepsleep-run.ts:95-97`）："**候选生成交向量，模糊判断交模型**"。
**反向边界**：水位/格式/隐私红线/账目守恒**必须确定性** —— **"可机检性"优先于"智能性"**。

## 9. 明确不做（汇总，防重提）

| # | 不做 | 理由 |
|---|---|---|
| N-1 | **不压缩注入面既有原则** | P8 **已实测否决**（可压面仅 302 字符 ≈10%，压了引入指针解析失败模式，`criteria.json:458`） |
| N-2 | **不把确定性判据改成模型判据** | 水位/格式/红线/账目必须可机检、可逐字节回归 |
| N-3 | **不做多相节律（NREM↔REM 交替）** | 成本 ×轮数，收益未证；排在 P5 之后另立 |
| N-4 | **不做 SHY 式"高频低价值"降权** | 需先有 R1 度量；现只处理"冷度" |
| N-5 | **不用 `epoch` 命名睡眠纪元** | 已被 `supply-ledger.ts` 占用（D-13） |
| N-6 | **不把"弃脚手架"实现为物理删除** | 默认 = 归档冷存/无损编码；物理删除是显式动作。成本不对称：留着只花可压磁盘，删了不可恢复 |
| N-7 | **不新增模型依赖** | B10；向量继续用本地既有 bge，LLM 继续走既有路由 |
| N-8 | **不为"用模型"而用模型** | 每个升级项必须先有**实证动机**（横切册 §3 三项各有实证） |
| N-9 | **不改 `consolidateTree` A/B/C/D 判定算法** | B2：411 行已是全仓第二大函数，只能抽新函数 |
