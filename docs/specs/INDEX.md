## 5. 使用方式

1. **按顺序施工**：S0 → S1 → S2 → S3 → S4。前一块未过验收，不启下一块。
2. **每块两步走**：先读该块 `-plan.md` 定方案 → 施工 → 用同块 `-acceptance.md` 验收。
3. **验收不通过即回退该块**，不影响已交付块（每块留全局热开关，缺省值 = 现状行为）。
4. **跨块问题**记入本索引 §6，不在块内私自扩范围。
