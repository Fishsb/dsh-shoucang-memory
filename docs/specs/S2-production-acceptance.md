# S2 · 生产链条验收方案

> 配套：`S2-production-plan.md`。**任一项 FAIL 即 S2 未完成。**

---

## 1. 验收断言

### A 类 · 触发与成本

| # | 断言 | 判据 |
|---|---|---|
| A1 | **无信号不唤醒 LLM** | 构造无预筛信号词的增量 ⇒ 零 LLM 调用（审计中**无** `audit.distill-run`，**有** `audit.distill-skip`） |
| A2 | **触发阈值生效** | `idle < 10min` 或增量 `< 200 字符` ⇒ 不触发 |
| A3 | **预算有界** | 材料超限时按 24,000 / 12,000 截断，且**留痕**（不静默丢弃） |

### B 类 · 契约合规（本板块核心）

| # | 断言 | 判据 |
|---|---|---|
| B1 | **每路输出都有 `typeId`** | 遍历 `writeDispatch` 的输出分支，逐一映射到 S0 契约；出现无对应者且**未被拒写** ⇒ FAIL |
| B2 | **拒写留痕** | 被拒的输出在审计中有记录（含原因），非静默丢弃 |
| B3 | **产出形态合规** | 新写入的 md 行满足 `[tag] … → notes/x.md §y` 或 `- … ← 源:`；环记录 `file=''` |
| B4 | **经 `record-shadow` 双写** | 写入后 `records.jsonl` 与 md 一致（对账门禁通过） |

### C 类 · 水位与可靠性

| # | 断言 | 判据 |
|---|---|---|
| C1 | **done 才推水位** | 构造"产物不可解析"场景 ⇒ 水位**不前进**、状态 `failed`、可重试 |
| C2 | **失败不留半成品** | 回滚后 md/records 无残留（原子写验证） |
| C3 | **重启可恢复** | 从 `distill-audit` 回放能重建水位（重启后不重复蒸馏、不漏区间） |

### D 类 · R1 复核（Tier-1）

| # | 断言 | 判据 |
|---|---|---|
| D1 | **助手侧内容可被读到** | 构造含 assistant 回复的会话 ⇒ 蒸馏材料中**确实包含**助手侧文本（不是仅 user 侧） |
| D2 | **回归断言在位** | 新增的断言能抓住"读不到助手侧"的回归（**修动前先让旧行为变红**——仓内实证纪律） |

### E 类 · 解耦与审计

| # | 断言 | 判据 |
|---|---|---|
| E1 | **关蒸馏不影响消费** | 置蒸馏关闭 ⇒ S4 通路仍能从库内既有内容供给（DS6 三域解耦） |
| E2 | **类型分布可数** | 一次蒸馏后能数出本次产出的各 `typeId` 数量（来自 `ledger.jsonl`） |
| E3 | **X6 有决断** | `episodes.jsonl` 补生产者 or 正式退役，二者之一**已落**并留痕；不得悬空 |

### F 类 · 工程纪律

| # | 断言 |
|---|---|
| F1 | `audit-wiring` I1/I2 不破 |
| F2 | `audit-fnspan` 无新增超 120 行（`mountDistillEvents` 123 不得再涨） |
| F3 | `check-hardcode .` 零硬编码 |
| F4 | 新增测试/机检**已登记** `check-runner`；`check-runner` 全绿 |
| F5 | `audit-architecture`：循环 0、隐藏环 0 |

## 3. 关键真值表（防假绿）

| 场景 | 期望 | 理由 |
|---|---|---|
| 蒸馏"跑成功"但**产出 0 条** | **FAIL** | 仓内真实病史：写门 30 字硬上限与 prompt 错位 ⇒ **深睡长期零产出**（`architecture-review` §7.2）。"成功"必须看**产出数**，不看 `stop=completed` |
| 审计有 `distill-run` 但**无类型分布** | **FAIL** | 数不出"产了什么"就无法验收 B1 |
| R1 修复"存在"但无回归断言 | **FAIL** | 该缺陷曾静默存在（全仓仅一处读 assistant 事件）⇒ 无断言必复发 |
| 水位推进了但产物不可解析 | **FAIL** | 违反 `[原则] 批处理水位即真相` |
