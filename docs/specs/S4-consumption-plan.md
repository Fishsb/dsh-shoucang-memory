# S4 · 消费链条方案（库 → 上下文）

> **板块职责**：把库内容按**人类三层（任务/行动/认知）**分时机供给模型。**不写库**（除审计流）。
> **依赖**：S0–S3 **全部**（它是收口：前面产出的类型必须在这里可达）。
> **证据**：【读码】五通路 ·【实测】MCL 审计 ·【活体】本会话运行观测。

| 是 | 不是 |

## 3. 目标：三层供给结构

### 3.1 三层 × 内容类型

| 层 | 行为（人类） | 供给 | 时机 | 判据 | 预算 |
|---|---|---|---|---|---|
| **外层 · 任务级** | 预见→表现→反思 | 原则 · 偏好 · 边界 · **效能** | 会话开始 + 收尾 | always | stable |
| **中层 · 行动级** | 行动→监控偏离→控制 | 路径 · **流程判据** · 偏离信号 · 到期承诺 | 任务开始 + **执行中** | 任务型 + due | **process（新）** |
| **内层 · 认知级** | 感知→检索→判断 | 指针 · 情境记忆 · 事实 · 关联 | **每步** | 情境键 + 相关性 + 熟悉度 | dynamic / mcl / situation |

### 3.2 核心机制：判据常驻 + 材料按层按需

```
常驻判据（三层合计 <200 字符）
  外层：念一遍任务目标与红线
  中层：连续 2 次无实质进展 ⇒ 停走回溯；线索变弱 ⇒ 换向；承诺到期 ⇒ 主动提
  内层：先情境键、后内容相似；证据冗余即停
        ↓ 触发才注入
材料（按层/按情境/按需）—— 见 §3.1
```

**项目已自发做了第一步**：`mcl.ts:165-169` 的 `THIN_CONTRACT` 就是极小判据——但只在慢通道、只在任务首步。本板块把它**推广到三层全时机**。

【活体证据】本会话观测：慢通道注入 `判据域分治` / `深睡吸收过程数据` / `记忆质量审查`——**相关性良好，但三条全属内层/方向，无一条提供"执行中的过程判据"** ⇒ 印证中层缺位。

### 3.3 预算模型（单一实现 + 独立槽）

| 槽 | 归属层 | 现在 | 目标 |
|---|---|---|---|
| `stable` / `dynamic` / `oneshot` | 外/内/外 | 手写三层（A） | 统一走 `SupplyBudget`（B） |
| （MCL） | 内 | 600 独立 | 保留 + 补停止准则 |
| `situation` | 内 | 300 / topN 3 | 额度与库规模挂钩 |
| **`process`（新）** | **中** | **不存在** | 独立预算，**缺省 0**，可回滚 |
| `serendipity` | 内 | 0（关） | 不动 |

【注册表既有纪律】独立槽的理由是"**改权重解决不了，只能分槽**"（`situation`/`serendipity` note）——`process` 沿用同一理由。

## 4. 施工卡

| 步 | 动作 | 落点 | 依赖 | 风险 |

| **S4-7** | **两条件分流**：`fast` 增「环境有规律 + 有反馈机会」（替代"放宽 `hasHighConf`"） | `mcl.ts` `decision-ring` | S4-6 | 中 |

## 5. 不变量（本板块特有）

| # | 不变量 |
|---|---|
| R1 | **恒定面「必在 + 安全带」**：P 层不被比例裁（`budgetChars=4000` 只防无界膨胀） |
| R2 | **被裁必须留痕**：任何被预算挡下的行须有可见化提示（不静默丢记忆） |
| R3 | **块内裁行不丢块**：AGENT/USER 画像各自配额，不得挤掉整段 |
| R4 | **独立槽不得互挤**：`situation`/`process`/`serendipity` 各有预算 |
| R5 | **不新增常驻注入点**（仓内既有纪律）：新供给走既有挂点 |
