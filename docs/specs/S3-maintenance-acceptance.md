# S3 · 维护链条验收方案

> 配套：`S3-maintenance-plan.md`。**任一项 FAIL 即 S3 未完成。**
> **本板块的特殊性**：它是**唯一重写历史**的链条 ⇒ 验收必须证明**两件事**：① 迁移没改变行为；② 它**真的在产出**（不是空转）。

---

## 1. 验收断言

### A 类 · 独立性与等价（X2）

| # | 断言 | 判据 |
|---|---|---|
| A1 | **维护链可独立启停** | 关闭维护链 ⇒ 蒸馏不受影响；反之亦然 |
| A2 | **行为等价**（**最高优先**） | 同窗口同材料，迁移前后产出**逐字节一致**（基线存档比对） |
| A3 | **无新增惰性桥** | `check-bridges` 仍 0 边 |
| A4 | **装配函数 ≤120 行** | `audit-wiring` I1 不破（新函数单独计） |
| A5 | **composition 契约未破** | 句柄显式传递；`createDeepSleep` 的依赖仍 ≤12 字段 |

### B 类 · 触发与门控

| # | 断言 | 判据 |
|---|---|---|
| B1 | **停滞 ≥3h 才触发** | 有活跃会话时**保守不睡**（日志可见"探测未完成，本轮跳过"——**该保守行为正确**，不得被改成激进） |
| B2 | **探针不误杀长任务** | `long-run`（有输出增长）不得被判 `stall` |
| B3 | **水位 done 才推** | 构造失败 ⇒ 水位不动、可重试 |

### C 类 · 产出有效性（**本板块核心**）

| # | 断言 | 判据 |
|---|---|---|
| C1 | **不是空转** | 一轮真实深睡后，产出数 **> 0**（新 `[原则]`/`[路径]`/环记录/叙事 至少一类）——【实测】基线 `write.consolidate` 仅 8 条、历史 34 次中成功 2 次，故此项**必须有硬证据** |
| C2 | **空转可见** | 若产出为 0，审计必须给出**原因**（`no-traces` / `all-rejected` / `no-parent` / `error` 之一）且可在面板一眼看到 |
| C3 | **产出带源指针** | 每条升格/合并的行都有 `← 源:` 或 `→ notes/` 指针（Q2） |
| C4 | **写门未被绕过** | 产出全部经 `write_gate` + `record-shadow` 双写；`records.jsonl` 与 md 一致 |

### D 类 · 四项补齐机制

| # | 断言 | 判据 |
|---|---|---|
| D1 | **M2 遗忘候选被消费** | 审计出现 `interferenceCandidates: N`（**2026-09-14 已补该字段**）。消费判据**须区分空候选**：`N>0` ⇒ 应消费 ≥1 条；`N=0` ⇒ 审计须显示**输入 0**（不得把"没候选"记成"没消费"）。⚠ **实测修正**：当前库 `forget: 0`（主库 09-13 才重建，90 天窗口内不可能有"≥90 天零命中"的冷节）⇒ 原判据「一次深睡至少消费 1 条」在**空候选时不可能、且不应**满足（硬消费=造数据） |
| D2 | **M3 跨日回放** | 审计中 `replayHits` 非零（**2026-09-14 已补该字段**；实测真实库**输入 10 条**：`env.md §DSH 环境（48 次）` · `lessons.md §DSH 自托管约束（43 次）` · `flows.md §深睡蒸馏（31 次）`…）；「≥1 条原则被跨日二次激活」需**真实深睡产出**，待自然发生 |
| D3 | **M1 REM（若开启）** | `crossTopic` 产出**通过宿主硬门**（≥2 个不同 § 源指针）；未开启则**必须记录"缺省关"状态**（不假装已覆盖） |
| D4 | **M4 健康度对账** | ✅ **2026-09-14 已达成**：`sleepSummaryOf` 出聚合（有产出/空转/异常/旧格式四类 + 比率），面板 `/cognition/report` 的 `sleepSummary` 暴露；数值来自 `deep-sleep` 审计（**实测 42 轮：有产出 3 · 7.1%**），非估算 |

## 3. 关键真值表（防假绿）

| 场景 | 期望 | 理由 |
|---|---|---|
| `stop=completed` 但产出 0 条 | **FAIL** | 仓内真实病史：**深睡长期零产出**（写门 30 字上限与 prompt 错位）。`completed ≠ 成功` |
| `gate=all-rejected` 被当成"正常" | **FAIL** | 拒收率是健康指标，不是通过条件 |
| 迁移后"跑通了"但**未比基线** | **FAIL** | A2 是本板块唯一能证明"没改坏"的断言 |
| 深睡水位推了但产物不可解析 | **FAIL** | 违反 `[原则] 批处理水位即真相` |
| REM 未开启却声称"已支持跨主题" | **FAIL** | D3 要求**显式记录缺省关** |
