## U1 · 按 fan-in 逐个抽服务（**不做大 ctx 一次性迁移**）

| # | 断言 | 判据 |
|---|---|---|
| **U1-1** | **先红**：断言"顶层可变符号已全部抽出"**首跑必须 FAIL** | 实测 **35 个 `var`**（被赋值 **49 次**）⇒ 不红即断言无效 |
| **U1-2** | **一次只抽一个服务**，按 fan-in 降序 | 顺序：`CSS`(8) → `UI`(**34**) → `Derive`(**25**) → `Cfg`(15) → `Log`(12) → … |
| **U1-3** | 每抽一个**立即验** | `ui-geo-regress` 100 PASS（**不含并行抽取**） |
| **U1-4** | **真·可变状态留在入口** | `refs`/`inject`/`Store`/`Fold`/`memoryViewScroll` **不搬出**，按需以参数传给少数函数 |
| **U1-5** | **不引全局** | 无 `window.xxx =`／隐式全局 |
| **U1-6** | **不一次性改 69 个函数签名** | 单卡改动的函数数应**≈该符号的 fan-in 的一个子集**，不得一次动全部（对抗实测：69/90 引用可变符号） |
| **U1-7** | **模块形态一并处理** | `body.js` 是**手写 IIFE + 条件 CJS 导出**（`module.exports` ×2）⇒ 拆 ESM 时包装形态明确 |
