且「下拉为原生实现……**已被像素级证据否决**」）。照原方案做会**把门打红**。

| **U3-2′** | 该判因从**注释**提升为**可机检说明** | 现状只以 `ui-geo-regress` 断言形式存在 |

## U5 · 【对抗新增】**补行为级证据**（F 项发现证据链有缺口）

`ui-geo-regress` 实测：断言覆盖几何 + 组件承载 + `shadowRoot` + `.click()` **8 次**，
但 **`submit` = 0 · `fetch(` = 0 · `POST` = 0** ⇒ **不测"提交 → RPC → 回流"**。

| # | 断言 | 判据 |
|---|---|---|
| **U5-1** | **一条 `/save` 端到端正常路径**（`test-route-schema` 只覆盖了"400 不入 handler"） | 请求 → 200 → **数据回流且 DOM 更新** |
| **U5-2** | 拆分前后**同一次提交的 DOM 差异为空** | 可对拍（拆分前存基线） |
| **U5-3** | 反例自证：故意断一条回流 ⇒ U5 必须红 | 断言语义有效 |
