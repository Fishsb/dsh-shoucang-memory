# ADR-0003：守藏退役归档：插件下线，suite 蒸馏与集合职能终止（记忆栈整体退役，记忆职责移交 dsh-auto-memory）

> 状态：accepted

## 背景

本仓 ADR-0001（重定义为集合中枢）与 ADR-0002（蒸馏固化归属守藏）确立的「守藏=UI+设置界面+单一蒸馏器」体系运行一天后，用户评估了第三方 DSH 插件 Aik358/dsh-auto-memory（主动联想记忆：自动沉淀+零提示召回+技能固化）并装入 dsh-web 验证通过。auto-memory 自带沉淀与守藏蒸馏唯一权（F-008/ADR-0002）构成知识双轨冲突。用户拍板（2026-09-07 00:14）：**旧记忆栈整体退役——守藏插件与记忆插件一并卸载隐藏，pmg 保留**（决策记录=pmg 权威仓 docs/map/decisions/ADR-0003）。

## 决策

1. **插件下线归档**：`~/.dsh/plugins/shoucang-panel` 软链删除（本仓 `D:\FF\shoucang` 本体保留）；守藏 UI、scheduler 蒸馏器、panel 全部端点随插件下线。
2. **数据零损失**：`~/.dsh/suite/knowledge/`（三索引+pending+audit+水位 distill-watermark.jsonl）原封保留；备份 `~/.dsh/backups/memory-stack-retire-20260907-001554/`。
3. **本仓转冻结归档仓**：ADR-0001（集合中枢定位）与 ADR-0002（蒸馏唯一权归守藏）双双 superseded；F-001/F-008 相应 superseded。仓库文档已全量改写为退役实态，此后不再常规演进。
4. **记忆职责移交**：dsh-web 记忆职能由 `@a9i5k4/dsh-auto-memory` 单独承担；pmg 仓为唯一活跃治理仓，开发知识权威=pmg devref 卡库。
5. **回滚路径**：重建软链 `ln -s /d/FF/shoucang/plugins/shoucang-panel ~/.dsh/plugins/` + 还原 profile cordis.patch.yml.bak + 重启 dsh-web；重启期后回滚需合并 suite 水位行防重蒸（蒸馏与 auto-memory 沉淀并行期）。

## 后果

正面：消除 auto-memory 沉淀与守藏蒸馏的双轨冲突；dsh-web 插件栈精简；本仓与记忆仓从三方协作义务（宪章三副本哈希同步、双查纪律、白名单门禁双端）中解脱。

成本/注意：①守藏 UI（记忆仪表盘/治理知识库板块/蒸馏统计卡/欢迎游览）全部失效，UI 数据契约卡转历史；②suite 知识区不再增长（蒸馏终止），历史数据只读；③panel 的 pmg 只读端点（/api/shoucang-panel/pmg/*）失效——pmg 卡库此后仅经 CLI 访问；④若未来重启蒸馏，需先比对 suite 水位与 auto-memory 沉淀防重复。

## 替代方案

- **双轨并行**（守藏蒸馏 + auto-memory 沉淀）：唯一权冲突、双写风险、token 双耗，用户未选。
- **关 auto-memory 沉淀保守藏栈**：引入第三套召回注入，复杂度反升，未选。
- **仅下线不改文档**：治理文档持续失真，用户选全量修订（方案 B）。
