# ADR-0001：守藏重定义为 DSH 插件集合中枢（suite hub）

> 状态：superseded（2026-09-07 守藏退役归档 ADR-0003：插件已从 dsh-web 下线，本决策转历史）

## 背景

守藏前身=独立记忆插件项目（D:\lk\FF\shoucang，2026-08-26 立项 / 08-27 停止开发），其记忆归档蒸馏职责已由 `@dsh-external/dsh-managing-memory` 事件驱动蒸馏（ADR-0004 方案 E）实现并超越。2026-09-06 用户拍板：旧方向资产重新裁决，项目重定义迁入独立新仓（本仓）。

## 决策

守藏重定义为 **DSH 插件集合中枢（suite hub）**：UI + 全部集合插件设置界面 + 协调调度。装守藏=获得集合入口，成员插件（记忆插件/pmg/未来…）独立可装可用；守藏不抢业务——知识裁决归记忆插件（R0 路由），项目治理归 pmg。资产裁决四项：① idle-review 归档蒸馏废弃（蒸馏唯一权=记忆插件 watcher）② 画像/记忆/wiki 三板块废弃（记忆库+pmg 卡库承接）③ 4-Gate 降级复用为 suite 路由、G30 证据计数保留 ④ 向量检索 UI 悬置、scnote 保留。配置模板升 v2（`suite:` 成员注册表，archive:/boards:/lifecycle: 删除）。

## 后果

正面：与记忆插件职责边界清晰、零重复建设；集合生态入口统一，成员可独立安装。成本：panel UI 冻结待按集合需求适配（新增「插件集合」视图）；scheduler 待重定义为 suite-manager（`shoucang_suite` 装配检测）；旧仓设计稿（docs/）留冻结仓不入新仓。

## 替代方案

- **继续原记忆归档方向**：与记忆插件方案 E 完全重叠且已被超越，弃。
- **并入主仓统一治理**：HANDOVER 建议独立成图（主仓 sync 已把 suite 排除在模块外），且本仓为开源发布仓、治理文档本地化，独立边界更干净，弃。
