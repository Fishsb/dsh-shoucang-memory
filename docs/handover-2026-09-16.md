## 六、本轮固化的纪律（跨任务可复用）

1. **"文件存在"不得作为"本次动作成功"的判据**（出图通道曾因此**整环失效而不自知**）⇒ 产出型步骤一律「先删目标 → 执行 → 按本次产物判」。
2. **渲染类判据一律「图证 + DOM 几何」双判据** —— 纯像素对视口折叠线以下**系统性失明**。
3. **源码文本断言必须容"编译产物形态"**（分号/引号/缩进），否则误报红会让你去改门禁而不是改自己。
4. **新增配置键三处齐全**：zod schema + 接口 + **返回值映射**（缺一则"假接线"，且 schema 齐全时**白名单不报警**）。
5. **删模块是三件事**：`src/` + `lib/` 产物（tsc 不删）+ **已安装副本**产物（部署只覆盖不删除）。
6. **可变状态必须装箱**（模块级 `let` 撞 `audit-architecture` 可变全局棘轮，基线 0）。
7. **测违规的夹具本身可能违规**（测隐私的样本可能泄隐私、测硬编码的样本可能含盘符）。
8. **口径的复杂度增加 ≠ 更准**：S-P5b 按标签分类把真读数改坏（74/54 虚高），S-P5b′ 改回**文件职责**后收敛到 **26/4/23**。
