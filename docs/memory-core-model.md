# 守藏记忆核心模型 v6（设计定稿；2026-09-10 用户拍板五原则：树状自动分裂维护 · 只注入压缩指针 · 指针承载"大概有什么"供快速路由 · 执行中按需取详情 · 指针自动维护且同类同事实唯一）

> 状态：设计定稿，待分阶段实施。来源：2026-09-09 连续会话收敛（模型 v3→v4→v5→v5.2→v5.3→v5.4），结合外部研究（AWM/ExpeL/GA/Letta/Reflexion，见 `docs/agent-reflection-research.md`）与 dsh-auto-memory 源码考古（GitHub [Aik358/dsh-auto-memory](https://github.com/Aik358/dsh-auto-memory)，M7/M8 文档）。实施启动时同步修订 spec（v16→v17+）、蒸馏契约、架构文档（指纹过期重生成）。
>
> v5.3（2026-09-09 用户拍板北极星）：**除硬件/平台能力约束这一唯一天花板外，agent 应像一个伙伴、一个全能助理——守藏不设任何人为边界**。守藏负责供给让"伙伴"成立的记忆底座（人格一致性、经验复用、懂主人、成长可见），主动行为由 agent 层依画像执行。

> 本文档是**方向与机制的唯一参考**：代码实现凡与本文冲突，以本文裁决为准（除非用户后续拍板修订本文）。

## 1. 定位（一句话）

让 agent 在真实任务中**像人一样成长**的伙伴式全能助理记忆——长的是"可复用认知 + 人格"，不是笔记堆。唯一天花板=硬件/平台能力（本机显存与模型档位、上下文长度、出网与成本、宿主进程生命周期、多模态需外部设施）；除此之外不做人为限制。

- **北极星（v5.3）**：伙伴不是工具。伙伴会：记得你（USER 画像 + 晨起摘要）、越用越懂你（纠偏沉淀 + 人格双面成长）、在你卡住时递上上次的经验（读侧召回）、主动到点提醒你关心的事（偏好/时机契约入 USER，行为由 agent 层执行）、有自己的边界与判断并保持一致（AGENT 画像 + 整编）。
- 私人助理人格 = **稳定底色 + 按需唤醒的成长档案**，双面分测：**判断/边界**（AGENT 画像 + 同型任务决策路径一致性）与**沟通风格**（USER 风格小节 + 主人纠偏反馈）。
- 记忆是"工作台的摆放"不是"仓库的搬运"：常驻的只有薄工具清单（索引行），用到哪件才去仓库取哪件（懒展开），用完把"新工具怎么造的"记回仓库（沉淀），过一阵清点淘汰没用的（整编）。

## 2. 三叠分层

| 层 | 尺度 | 内容 | 纪律 |
|---|---|---|---|
| 底色/身份 | 月~年 | 角色定位、服务边界、汇报方式（AGENT 底色）；主人的基本盘（USER 底色） | 薄常驻 1-3 行、**字节稳定**（保前缀缓存热），不进蒸馏/检索 |
| 可复用经验 | 周~月 | [原则]/[路径]/notes 教程、USER·AGENT 画像条目 | 平时休眠，**任务时按需召回** |
| 进行中状态 | 会话内 | 当前任务进度、刚改到哪 | 属于工作台，**默认不入长期库**（一次性进度丢弃/只落 devref） |

## 2.5 树状知识结构（v5.4 核心 · 数据形态）

记忆库 = **一棵运行期自动生长的多叉树**，索引指针是冠层入口，向后是层层分裂的知识子树。树的全部节点由
蒸馏/深睡在运行中建立与扩展——**不存在手工摆设位**（面板展示的都是自动搭建的；编辑只发生在树的细节正文，
结构变更仅深睡/蒸馏执行）。

```
索引行（冠层指针）            [经验] 记忆脚本参数坑 → notes/agent.md §学习史
notes/agent.md（树干）        ## 学习史            ## 演化
  ### 2026-09 批次（子节）      ▾ 小节可向下分裂
    - 细则…（叶）
```

- **分裂（写，事件蒸馏）**：蒸馏产物定位 notes 时——若主题归属既有 `##` 小节，则：
  ① 内容少量 → 并入小节正文；② 内容成体系（≥ 3 条细则/一独立方法）→ 在该小节下**新建 `###` 子节**（分裂），
  而非无脑平铺成大节；③ 主题无归属 → 新建 `##` 小节。分裂沿 `<父标题 /` 路径表达（如 `§学习史/2026-09 批次`）。
- **成长（循环）**：同一主题反复蒸馏 → 子节持续细分 → notes 文件内树的深度自然增长；多次同型任务成功后
  转正 [路径]（§4），其 checklist 落 `notes/flows.md` 的树节点——召回懒展开的正是这条链。
- **整编（深睡）**：深睡对树做减法与归并——合并语义重复的子节、降级长期未命中的冷枝（打 stale 标记）、
  子树过长（单小节 > 容量余量）时把低频分支拆出或回收；**树的形态由深睡维护，事件蒸馏只增不删**。
- **关联**：同一知识出现在多处（如 [原则] 同时被两个小节引用）→ 引用方只留 `→ notes/x.md §...` 指针行，
  实体唯一（在原始小节），跨引用 = 指针复用（不复制内容）——防同一教训多份漂移。
- **渲染与编辑纪律**：面板详情递归渲染树（## → ### → … 可逐层展开）；编辑 = 节点正文（走 write_gate）。
  **指针对人工编辑只读**（手工改指针会造成树结构错位）；指针的增/改/并是蒸馏/深睡的自动职责（见 §2.6），
  面板/对话不允许直接手改索引行——要改只能改正文树节点，指针由自动通道跟随。

## 2.6 指针生命周期（v6 · 用户拍板：指针自动维护，同类同事实只允许一个）

索引指针是"压缩路由层"，只注入它、由它路由去取正文——因此指针本身也必须被自动维护：

| 操作 | 属主 | 规则 |
|---|---|---|
| **新建** | 事件蒸馏 `newIndex` | 唯一性硬门：同库同文件下 ① 同 `[标签]`+同主题 → 拒；② 同标签 + 主题 bigram 重叠 ≥0.66 → 拒（近似同事实，留原指针）；拒绝落审计 `dup-index-topic` |
| **扩容** | 深度睡眠 `pointerOps.update` | 小节正文显著增补/概况过时 → 原地替换整行、只刷新概况短语（保 标签/主题/指针）；match 须逐字 |
| **重构** | 深度睡眠 `pointerOps.update` | 小节改名/合并导致指针 § 失效/漂移 → 更新指针 §（及概况）——树整编与指针跟随同 pass 完成 |
| **去重** | 硬门（拒新增）+ 深睡 update（并旧留优） | 同 标签+主题 两行 → 保留信息更全者、被留行合并概况；绝不双写 |
| **删除** | 审计裁决（人工/周期审计） | 指针不做自动删除；冗余由审计按 health exit3 提示处置 |

- 只读口径修正（v5.4"索引指针只读"易误读）：**对人工编辑只读、对自动通道（蒸馏/深睡）可写且必须自动写**。
- 指针行本体是"四要素压缩行"，注入面只放这些行 + [原则]/[路径]/L1 纪律；正文一律 read_section 懒展开。

> 与旧形态差异：v5.4 前 notes 小节是**平铺的教程段**（## 一层到底）；v5.4 起允许 ## 下 ###（多层递归），
> 分裂是**自动的**（蒸馏按内容量决定归并 vs 分裂），树深随使用增长。写门/召回/白名单骨架不变。

## 2.7 树层级语义与层义规范（v1 · 2026-09-10；"每层回答什么问题"决定内容与粒度，不自造——借用成熟笔记/记忆方法论对齐）

> 借鉴来源（不是从零发明）：① Anthropic Agent Memory 实践——文件/小节**按上下文预算切块**（"大记忆拆小块，检索才有意义"）；② 渐进式摘要（Progressive Summarization, Forte）——每层只留"下一步摘要"，展开才见细节；③ PARA/Zettelkasten **原子性**——一个节点=一个可独立理解的单元；④ 本仓既有 v5.4 树（## 锚 → ### 自动分裂）与 §8 模板（教程式三段）作为承载。

每层=一个"单元问题"，回答它才允许放内容：

| 层 | 节点 | 单元问题 | 内容与粒度 | 预算（展开单层即可回答） |
|---|---|---|---|---|
| L0 | 索引指针行 | 有这么个东西吗/大概是什么 | 标签·主题·概况(≤30字)·指针；零正文 | 注入面唯一常驻 |
| L1 | `##` 主题域 | 该主题的**稳定核心**是什么 | 教程式三段浓缩（目标/步骤/注意）可作第一层摘要；最多 1 组 根因/不适用 | ≤ ~8 要点行（≈一次 read_section 预算） |
| L2 | `###` 分面 | 主题下**某一正交子面/子坑/场景**的细则 | 单一子面细则/命令/反例/版本差异；小节名=子面名词 | 每子面 ≤ ~6 细则 |
| L3 | `####` 长尾 | 单条**时间序/逐案例**记录 | 事件史/版本演变 | 预期极少；无意义则不裂 |

**动作规范**：
1. 分裂判据（写入时）：新内容能并入 L1 一句概括→并；与 L1 现有要点**正交**的新子面→裂 `###`（父/子名并列可独立理解）；L2 已有 ≥3 子面且增量集中某子面→该子面**提级新 L1**（活动性 hot 候选供判）；新主题必须先 L1，禁跳层直造深节。
2. 命名：名词性短语；同层防重名/近重由 v6 唯一门 + consolidation 兜底。
3. **二级展开读写协议**（解决"一个指针后面一大堆"）：注入=L0 只读；命中 L0 → 只读 L1 正文；不满足且有 L2 → 返回 L2 标题清单（一行一个）→ 模型选面展开 `§父/子`；禁止一次拉全树。
4. 维护反向力：consolidation 并叶子；活动性 cold 子面→整编候选（并回 L1 或归档）；L1 超规模=审计处置项（不再是"深睡以后做"的悬空设计）。

## 3. 双环闭环

### 3.1 成长环（写）

1. **事件蒸馏**（即时小睡）：turn/end → idle → 增量提取 → 教程式 notes（白名单 + 源指针 + 审计）。
2. **收尾 episode**（每任务一行）：`{sid, intent, actions 骨架, outcome, 转录指针}` → `suite/knowledge/audit/episodes.jsonl`（保留上限 ~256 自动淘汰）。轨迹是"同类判定与转正"的数据源，**不存全文**（转录在宿主 sessions 可定位）。
3. **深睡整编**（离线回想）：停滞 ≥3h 触发 → 提炼/合并/降级 → 产出 **晨起摘要** delta。
4. **晨起摘要**：深睡 delta（≤3 行）于下会话开头注入；同一 delta 累计注入 ≥5 会话停注；48h 未更新标记 stale；无产出不生成。
5. **月度成长页**：审计按月聚合（新增/替换 [原则]/[路径]/画像统计 + 变化 diff），面板纯读展示，零新定时器——"人格在长"的可见物 + 一致性度量载体。

### 3.2 使用环（读）

1. **任务类型认领**：类型标签 + 语义相似双轨——标签管"分组入账"，相似管"排序召回"（向量只当排序器，主库仍是文件）。
2. **召回薄行**：词法地板为缺省（0 依赖）；dense 0.7 + lexical 0.3 融合为后续可选档（参照 M7 benchmark）；候选按"当前工作区优先 + 全局泛化分开"过滤；top-k ≤3。
3. **懒展开**：命中才按指针展开 notes checklist（目标/步骤/完成标准/注意）。
4. **小步执行**：按骨架小步走、每步验证，卡住时补检；宿主侧被动预取为可选兜底（P1，见 §5 打扰度）。
5. **收尾沉淀差异**：与骨架的 diff（并入蒸馏管线，不设第三并行写入者）。

## 4. 转正机制（硬化版）

借鉴 dsh-auto-memory M-04 procedure 状态机，保留 v17 "[路径] 行"方向并加护栏：

- 首任务成功收尾 → 产出**低置信候选**（`pending/flow-candidates/`，带类型标签；蒸馏采集过滤该子目录，防死循环）。
- **转正门槛**：成功 ≥2 次 **且跨会话 ≥2** + correction ≤30%（任何矛盾保持候选）+ **successCriteria 必写** → 升格写 AGENT.md `[路径]` 行（经 write_gate）。
- **行形态**：AGENT 行仅"指针 + 标题"（保容量），步骤 + 完成标准放 `notes/flows.md` checklist，召回时展开。
- **高风险动作**（部署/删除/SSH 类）：只降级为 hint（提示可参考），**永不因相似度自动执行**。
- **候选区治理**：滞留超龄（30 天或 3 次深睡未转正）→ 归档（教训价值当时已入 notes，只回收路径形态）。
- **同型判定口径单一**：候选文件内留历次判定日志（分数 + 口径），防 τ 漂移无法追溯。

## 5. 打扰度（读侧被动预取，P1 可选，默认关）

- 纪律参数（借鉴 packet 注入）：≤2 条/≤800 字/冷却 N 步/预算并入现有注入预算。
- **滞回双阈值**：per-session suppress/prefetch/emit，T_on 0.62 > T_off 0.52（参考初值），防阈值抖动。
- **shadow-first**：先审计抽查 + 影子日志攒真实误召样本 → 校准阈值 → 才开 active；不做合成 benchmark。
- 注入固定边界、静态部分字节稳定（前缀缓存友好）。

## 6. 防线

- **纠偏防误采五闸**：时态分流（以后/下次 vs 这次/太）→ 跨会话频次（弱反馈 ≥2 次不同会话）→ 强指令例外（以后+祈使否定可单次入，带源）→ 档位阻尼（不是翻面，带校正日期，同会话去抖合并）→ 蒸馏 LLM "稳定偏好"裁决兜底。
- **红线分级**：`[路径]` 变量化后可跨工作区沉淀（AWM 式）；`[原则]` 涉项目专名仍禁；pending 不作源指针（经蒸馏入 notes 才合法）。
- **容量 = 精选集**：深睡做减法（合并同类/降级重复/失效标记），write_gate 满员不只是拒收。
- **整编判定**：回读命中（access.log）客观初筛 + 深睡复审，不自评。

## 7. 度量

首轮成功率、路径步数、主人纠偏频率（风格/边界分类）、检索零命中降级数、画像零引用数；成长可见物 = 晨起摘要 + 月度成长页；判断/边界一致性 = 同型任务骨架相似趋势（数据与转正同源）。

## 8. 明确不做（防漂移；v5.3 口径：唯一天花板=硬件/平台能力，其余属「先不做/后做」而非禁区）

- **✏️ 主动行为由「不做」改为「底座支持、agent 层执行」**（v5.3 北极星）：守藏**不内置定时打扰实现**（不重蹈 auto-memory 全家桶），但负责供给伙伴感所需记忆——USER 画像沉淀"何时想被提醒/汇报粒度/关系模式"等偏好与时机契约、晨起摘要/月度成长页让"记得你/在成长"可见；主动提醒/问候等行为由 agent 本体依画像执行。
- 水线/交接上下文管理（职责归宿主会话层；宿主缺失属平台能力边界，不是记忆插件的补丁点）。
- 双场景 persona（AGENT/USER 双文件 + persona 档位已覆盖）。
- python 本地 embedding 全栈（重运行时撞零常驻红线；本地语义为未来可选档，接入需硬件预算评估——属能力档位而非禁区）。
- 外部 sources 多工具聚合（workbuddy/claude/codex，环境事实库定位）。
- 宿主自动任务分类（认领归 agent + 收尾回补同义词）。

## 9. 落地顺序（全保留、有序执行，每步过机检+CHANGELOG）

| 序 | 内容 | 验收 |
|---|---|---|
| ① | v17 写侧：[路径] 行 + 成败信号入归纳材料（`docs/sleep-v17-plan.md` 修正后执行：审计去重、write_gate tag 感知、先蒸馏后深睡） | AGENT.md 产出首条带源指针 [路径] 行 |

| ④ | 打扰度滞回 + 影子校准（默认关） | 影子日志有真实样本后再谈开 active |
| ⑤ | 向量档（0.7/0.3 融合）可选 | 上量后按 shadow 样本校准阈值再开 |
